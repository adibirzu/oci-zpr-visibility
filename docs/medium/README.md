# Medium copy package

1. Open `medium-copy.html` in a browser and choose Part 1 or Part 2.
2. Click **Copy title**, paste it into the title line, then copy the subtitle and article body separately. If browser clipboard access is blocked, use the selected-text fallback and press Command+C.
3. Replace each `[Insert screenshot: filename.png]` marker with the matching file from `images/`. Move its existing caption into the image caption field and use the alt text listed in `image-placement.json`.
4. Check the pasted headings, links, inline code and multiline commands in Medium. Clipboard formatting has been locally validated, but has not been tested in your authenticated Medium editor.
5. Save as a draft. This package does not publish anything.

The Markdown files are clean source copies. The text files are plain-text fallbacks; use HTML for formatted copying. Existing review context remains in the original articles, outside the copyable body. Tables were converted to readable paragraphs. Code snippets are unchanged.

All lab counts and screenshots refer to October 9, 2026. Current resource states were not rechecked during this editorial pass. The new features were tested in a local working revision; check CLI help before following the lab from a public clone.

Screenshots include private IPs and shortened OCIDs authorized for local review. Public IPs and FQDNs remain hidden. Public-release approval for these images remains pending. The internal DOCX and private receipts are excluded.

Medium references: [Story editor](https://help.medium.com/hc/en-us/articles/215194537-Using-the-story-editor), [Writing your first story](https://help.medium.com/hc/en-us/articles/225168768-Writing-and-publishing-your-first-story).
