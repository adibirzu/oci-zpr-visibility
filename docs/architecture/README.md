# Architecture diagrams

## `oci-zpr-visibility-pipeline.excalidraw`

The end-to-end data pipeline (collect → normalize → Upload API → Log Analytics →
dashboard), drawn as OCI components.

**Open / edit:** go to [excalidraw.com](https://excalidraw.com) → *File → Open* →
select this `.excalidraw` file. Export a PNG/SVG (*File → Export image*) to embed
in an article or wiki.

**Use the official OCI stencils:** the boxes are placeholders styled in Oracle
red. To replace them with the official Oracle Cloud Infrastructure icons, open
[libraries.excalidraw.com](https://libraries.excalidraw.com), add the
**Oracle Cloud Infrastructure / OCI** icon library, then drag each stencil onto
the matching placeholder box (ZPR, Security Attributes, Core/VCN, VCN Flow Logs,
Object Storage, Compute, Log Analytics, Monitoring, Management Dashboard,
Resource Manager) and delete the placeholder.

Component descriptions are in
[../article-oci-zpr-visibility.md](../article-oci-zpr-visibility.md) under
"Component glossary".
